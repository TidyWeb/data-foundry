Data Foundry

Random practice tables for pandas and data visualisation, built from small simulated businesses.

Each dataset is a tiny business: car sales, rentals, payroll, loans, shipments and so on. The values are random, but the relationships between them are built in — bigger houses cost more, deeper discounts sell more units, longer routes deliver late — so there is something real to find with pandas and charts, and nothing here is real data.

1

Pick a business

Choose one of the 24 below, or press Surprise me. Each card says what one row means and how many columns that business can supply.

2

Set the shape

Choose 1–{{ max_rows }} rows and how many columns you want. Core columns always appear; extras are added as you ask for more. You get a note if the business has fewer.

3

Generate, explore, download

You get the table and a guide to every column. Save it as CSV or Excel and load it with pd.read_csv. Each table has a seed: enter the same seed again to get the same table back.
